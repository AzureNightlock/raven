The goal of raven is:
* To create extremely easy dashboards, pages, etc
* To have it extremely well organised so that its very easy to debug and build
* To not worry about 1000+ untrackable node_modules, no package.json
* To be extremely quick and cover the essential stuff commonly used by downloading dependancies
* To create raw html,css,js that you yourself can debug


To compile:
raven compile

To lint:
raven lint
